# Como trabalhar neste projeto

Antes de alterar o código, leia `contexto/README.md`, `contexto/produto.md`, `contexto/design.md` e `backlog/README.md`. Consulte `backlog/erros.md` para problemas já conhecidos. Esses arquivos são o ponto de entrada; inspecione o código relevante depois, conforme a tarefa.

Atualize a documentação quando uma decisão de produto mudar. Registre bugs reproduzíveis em `backlog/erros.md` e mantenha `backlog/proximos-passos.md` com as próximas entregas. Não registre dados reais de clientes, segredos ou credenciais nessas pastas.

Este repositório é separado de `E:\dev\nureaos`. Não modifique o NureaOS para implementar o portal sem uma solicitação explícita. Não publique nem envie conteúdo real de clientes antes de haver autenticação e autorização por cliente.
