# Contexto rápido — Portal de Conteúdos Nurea

Este é o ponto de entrada para humanos e agentes. Leia nesta ordem:

1. `produto.md` — objetivo, usuários, jornadas e regras de negócio.
2. `design.md` — identidade e experiência mobile first.
3. `arquitetura.md` — implementação atual, limites e caminhos técnicos.
4. `../backlog/README.md` — estado e prioridades.

Fonte de produto mais extensa: [Projeto — Portal de Conteúdos para Clientes da Nurea](https://app.notion.com/p/3e52373f3184810ebaebc1ca43ad9d63?pvs=204). A documentação local resume as decisões necessárias ao desenvolvimento; se houver conflito, confirme com o usuário antes de alterar o comportamento.

Nome: **Nurea**. Transcrições por voz podem escrever “Nuria”; normalizar para Nurea. NureaOS é o aplicativo interno em `E:\dev\nureaos`; este portal é um projeto independente em `E:\dev\nurea-clientes`.

## Pastas

- `contexto/`: decisões estáveis e mapa do produto.
- `backlog/`: trabalho pendente, bugs e histórico de decisões de execução.
- `src/`: aplicação.
- `public/`: recursos estáticos de demonstração.

Não guardar credenciais, dados reais de clientes ou arquivos privados nessas pastas. Atualize os resumos após mudanças relevantes.
